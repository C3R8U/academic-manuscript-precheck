# Evidence and citation policy

1. Evidence anchor: each issue must cite a source block/page, a table/figure/equation index where present, and an exact brief quote copied from the source. If extraction broke the formula, say "formula needs visual verification" instead of guessing.
2. No source support = "requires verification". Do not assert a table reports X unless the table does. Avoid inferring causal effects from correlational results.
3. Web or publication verification: explicit DOI/title/author check required before "reference verified" claim; a plausible-looking source is not proof. Distinguish external sources from manuscript contents.
4. Quantitative reasoning: check denominators, totals, metric ranges, label meaning, dataset partition sizes, confidence intervals, units, number of folds vs random repeats, and test leakage. If all reported values are internally consistent but raw data unavailable, state "internal consistency checked; not independently reproduced".
5. In initial assessment, prioritize issues likely to materially change conclusion. Do not produce invented reviewer quotations, simulated p-values or new experimental outcome numbers.
6. In post-revision review, map each comment to exact revision evidence and classify as resolved / partly resolved / unsupported, but only when comparison sources exist.
7. The assistant should not publish the user's unpublished manuscript or samples in a public repository without permission.
8. Filename, paragraph ID, and PDF page locate text only; they do not guarantee figures/formulas were correctly extracted.
